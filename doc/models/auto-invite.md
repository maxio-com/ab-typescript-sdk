
# Auto Invite

## Enumeration

`AutoInvite`

## Fields

| Name | Description |
|  --- | --- |
| `No` | Do not send the invitation email. |
| `Yes` | Automatically send the invitation email. |

## Example

```ts
import { AutoInvite } from '@maxio-com/advanced-billing-sdk';

const autoInvite = AutoInvite.No;
```
